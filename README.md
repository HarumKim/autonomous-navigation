# 🚜 Autonomous Tractor Navigation – John Deere Project  
**5th Semester | Aug 2024 – Nov 2024**

As part of a **precision agriculture initiative**, this project focuses on the development of an **autonomous navigation system** for a John Deere tractor. The system enables the vehicle to follow **predefined waypoints with high accuracy**, enhancing efficiency and reliability in agricultural tasks.

## 📌 Project Overview

This repository contains the **firmware**, **control algorithms**, and **communication protocols** used to control and navigate a **differential-drive tractor platform** in real time using embedded systems and onboard sensors.

---

## ✨ Key Features

- 📍 **Trajectory Tracking System**  
  Designed and implemented to follow precise paths while optimizing field coverage.

- 📡 **Sensor Fusion for Localization**  
  Integrated **GPS**, **IMUs**, and **wheel encoders** to estimate the tractor’s real-time position and orientation.

- 🎯 **Dynamic Control Algorithms**  
  Developed control strategies for continuous adjustment of steering and speed, ensuring smooth and accurate path tracking.

- 🔗 **Robust Communication Protocols**  
  Enabled reliable communication between **STM32** and **Arduino** microcontrollers using **SPI**, **I2C**, **CAN**, and **UART** for real-time sensor data exchange.

---

## 🛠️ Technologies

- **Microcontrollers**: STM32H755 (ARM Cortex-M), Arduino  
- **Programming Languages**: C / C++  
- **Sensors**: GPS, IMU, Wheel Encoders  
- **Communication Protocols**: SPI, I2C, UART, CAN
